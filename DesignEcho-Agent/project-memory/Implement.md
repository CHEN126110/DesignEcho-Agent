# Implementation workflow

Use the public `CurrentTask.md` and `Intake.md` as alignment inputs.

1. **Intake** — record the user goal and affected capability.
2. **Orient** — inspect the real runtime path and current state.
3. **Classify** — identify Agent, Knowledge, Skill, Tool, Memory, Evaluation or Policy ownership.
4. **Evidence Check** — distinguish verified facts from assumptions.
5. **Design Gate** — confirm safety, privacy and architecture boundaries.
6. **Implement** — make the smallest coherent change.
7. **Verify** — run the relevant build, audit, smoke or live check.
8. **Write Back** — update public status, decisions and release notes when material.

Never place private project history, credentials or customer assets into public planning files.
