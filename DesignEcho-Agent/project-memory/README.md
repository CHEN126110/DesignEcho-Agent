# Public project memory

This directory contains the small, public planning state used to keep contributors and automation aligned.

- `Prompt.md`: durable project objective and boundaries.
- `CurrentTask.md`: current public demand-alignment card.
- `Intake.md`: incoming requests and their planning status.
- `Plan.md`: active milestones.
- `Status.md`: verified public status.
- `Implement.md`: contribution workflow.
- `Backlog.md`: executable follow-up work.
- `Decisions.md`: accepted architecture or governance decisions.
- `Risks.md`: known risks.
- `project-state.json`: machine-readable projection of the active request and plan.

Do not store customer information, credentials, local paths, private design assets, runtime transcripts or internal business history here. `CurrentTask.md` and `Intake.md` must remain synchronized with `project-state.json` when the active public plan changes.
