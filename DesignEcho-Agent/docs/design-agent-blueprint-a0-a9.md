# 设计 Agent 完整架构概念（A0–A9 蓝图）

> 来源：用户脑图 `设计Agent.mm`（2026-06-11 导入仓库，作为多智能体架构的权威概念蓝图）。
> 核心结论：长期 = 1 总控 + 9 专业共 10 个逻辑 Agent；第一阶段落地合并为 6 个执行模块；
> 全体 Agent 共同读写 Design Project State；评审驱动按退回规则回到对应角色。
> 实现状态对照见 CLAUDE.md；本文件只记录概念本身。


## 0. 系统闭环总流程

- 输入产品信息 / 图片素材 / 设计目标
- A0 总控编排 Agent
- A1 需求采集 Agent
- A2 商品 / 素材理解 Agent
- A3 用户 / 市场洞察 Agent
- A4 卖点 / 文案策略 Agent
- A5 参考 / 视觉方向 Agent
- A6 设计规划 Agent
- A7 执行生产 Agent
- A8 审核优化 Agent
- A9 交付 / 复盘 Agent
- 更新知识库，反哺下一次设计

  - 平台与尺寸
  - 品牌信息
  - 目标用户

  - 版式规划

  - 交付文件

## A0 总控编排 Agent

- 定位
  - 整个设计Agent系统的大脑
  - 负责流程调度、状态判断、任务分发、版本控制
- 输入
  - 用户原始需求
  - 上传的产品图片或素材
  - 历史项目状态
  - 可用工具列表
  - 知识库或模板库
- 核心流程
  - 1. 接收任务
    - 识别用户要做什么设计
    - 判断任务是主图、详情页、海报、社媒图、品牌物料、UI界面还是其他类型
    - 记录用户已经提供的信息
  - 2. 判断信息完整度
    - 检查是否有产品信息
    - 检查是否有目标平台
    - 检查是否有画面尺寸
    - 检查是否有品牌风格
    - 检查是否有素材
    - 检查是否有明确产出格式
  - 3. 生成缺失信息清单
    - 必须补充的问题
    - 可以默认处理的问题
    - 暂时不影响推进的问题
  - 4. 制定工作流
    - 明确先调用哪个Agent
    - 明确哪些Agent可以并行
    - 明确哪些Agent必须等待前置结果
  - 5. 分发任务
    - 给每个Agent提供必要上下文
    - 限制每个Agent只处理自己的职责范围
    - 要求每个Agent输出结构化结果
  - 6. 汇总结果
    - 合并各Agent输出
    - 更新Design Project State
    - 判断是否进入下一步
  - 7. 处理退回
    - 审核不过则回到对应Agent
    - 信息缺失则回到A1
    - 素材不足则回到A2
    - 卖点不清则回到A4
    - 版式问题则回到A6
    - 执行质量问题则回到A7
  - 8. 控制版本
    - 记录V01、V02、V03
    - 记录每版修改原因
    - 记录最终通过版本
- 输出
  - 项目工作流计划
  - 当前任务状态
  - 缺失信息列表
  - Agent调用顺序
  - 版本记录
  - 下一步动作
- 判断标准
  - 每一步是否有明确输入
  - 每一步是否有明确输出
  - 是否可以推进到下一个Agent
  - 是否需要向用户追问

## A1 需求采集 Agent

- 定位
  - 把模糊需求转成可执行的设计Brief
  - 不负责设计，只负责把需求问清楚
- 输入
  - 用户描述
  - 用户上传素材
  - 过往品牌信息
  - 平台要求
- 核心流程
  - 1. 确认任务类型
    - 电商主图
    - 电商详情页
    - 商品海报
    - 小红书封面
    - 抖音直播间图
    - 品牌KV
    - Banner
    - UI页面
    - 包装设计
  - 2. 确认产出目标
    - 提升点击率
    - 解释产品卖点
    - 强化品牌感
    - 促进转化
    - 展示活动优惠
    - 做新品发布
    - 做内容种草
  - 3. 确认平台与尺寸
    - 平台名称
    - 画布尺寸
    - 横版或竖版
    - 安全区要求
    - 文件格式要求
  - 4. 确认品牌信息
    - 品牌名称
    - 品牌调性
    - 主色与辅助色
    - 字体偏好
    - 禁用风格
    - 已有VI或参考案例
  - 5. 确认目标用户
    - 性别
    - 年龄
    - 消费能力
    - 审美偏好
    - 购买动机
    - 主要顾虑
  - 6. 确认产品信息
    - 产品名称
    - 产品品类
    - 产品规格
    - 材质成分
    - 核心功能
    - 使用场景
    - 价格带
    - 竞品差异
  - 7. 确认限制条件
    - 禁止使用的词
    - 不能夸大的卖点
    - 不能改变的素材
    - 必须出现的元素
    - 必须规避的平台规则
  - 8. 生成设计Brief
    - 将信息整理成结构化Brief
    - 标记确认项
    - 标记假设项
    - 标记缺失项
- 输出
  - 设计Brief
  - 缺失问题清单
  - 项目基础参数
  - 设计目标优先级
- 质量检查
  - 是否知道要做什么
  - 是否知道给谁看
  - 是否知道在哪里用
  - 是否知道画面必须表达什么
  - 是否知道不能表达什么

## A2 商品 / 素材理解 Agent

- 定位
  - 理解产品本身和图片素材能支持什么设计表达
  - 解决“素材能不能用、该怎么用”的问题
- 输入
  - 产品图片
  - 场景图
  - 细节图
  - 产品参数
  - A1输出的设计Brief
- 核心流程
  - 1. 识别产品基础信息
    - 产品品类
    - 产品外观
    - 颜色
    - 材质
    - 结构
    - 规格
    - 使用方式
  - 2. 分析素材类型
    - 主图素材
    - 细节素材
    - 场景素材
    - 模特素材
    - 包装素材
    - 图标素材
    - 品牌素材
  - 3. 分析素材质量
    - 清晰度
    - 分辨率
    - 构图角度
    - 光影质量
    - 背景复杂度
    - 是否适合抠图
    - 是否存在压缩损坏
    - 是否存在变形
    - 是否存在色差
  - 4. 提取可视化卖点
    - 外观卖点
    - 材质卖点
    - 结构卖点
    - 工艺卖点
    - 尺寸卖点
    - 使用效果卖点
    - 对比展示卖点
  - 5. 判断素材用途
    - 哪张适合做主视觉
    - 哪张适合做细节放大
    - 哪张适合做背景氛围
    - 哪张适合做对比图
    - 哪张不建议使用
  - 6. 判断素材缺口
    - 是否缺少正面图
    - 是否缺少细节图
    - 是否缺少使用场景图
    - 是否缺少对比图
    - 是否缺少品牌Logo
    - 是否缺少证据型素材
  - 7. 生成素材处理建议
    - 是否需要抠图
    - 是否需要调色
    - 是否需要统一光影
    - 是否需要背景替换
    - 是否需要AI补图
    - 是否需要重新拍摄
- 输出
  - 产品理解卡
  - 素材诊断报告
  - 素材用途标签
  - 素材缺口清单
  - 素材处理建议
- 质量检查
  - 是否准确识别产品
  - 是否准确判断素材可用性
  - 是否能说明每张素材适合干什么
  - 是否发现素材缺口

## A3 用户 / 市场洞察 Agent

- 定位
  - 找出用户真正关心的问题
  - 把用户疑虑转成设计应该解决的信息点
- 输入
  - A1设计Brief
  - A2产品理解卡
  - 用户评论
  - 问答内容
  - 竞品页面
  - 行业经验库
- 核心流程
  - 1. 建立目标用户画像
    - 用户是谁
    - 在什么场景下购买
    - 为什么需要这个产品
    - 预算敏感度如何
    - 审美偏好是什么
  - 2. 收集用户关注点
    - 功能关注
    - 材质关注
    - 尺寸关注
    - 舒适度关注
    - 搭配关注
    - 使用场景关注
    - 售后关注
    - 安全感关注
  - 3. 收集用户购买疑虑
    - 会不会不好用
    - 会不会不适合自己
    - 会不会质量差
    - 会不会和图片不一致
    - 会不会使用麻烦
    - 会不会不耐用
  - 4. 分析竞品表达
    - 竞品主图强调什么
    - 竞品标题怎么写
    - 竞品详情页先讲什么
    - 竞品视觉风格是什么
    - 竞品是否用了对比表达
    - 竞品是否用了场景表达
  - 5. 建立痛点分类
    - 必须优先解决的痛点
    - 可以辅助表达的痛点
    - 不适合本次设计表达的痛点
  - 6. 转成设计机会点
    - 哪些疑虑需要文字回答
    - 哪些疑虑需要图片证明
    - 哪些疑虑需要对比展示
    - 哪些疑虑需要场景展示
  - 7. 生成洞察结论
    - 用户最关心的3个问题
    - 最能促进转化的3个卖点
    - 最应该避免的表达误区
- 示例：袜子类产品用户疑虑
  - 长度
    - 能过膝吗
    - 显腿长吗
    - 穿上是否和图片一样
  - 稳定性
    - 会下滑吗
    - 会卷边吗
    - 袜口会不会松
  - 舒适度
    - 会勒吗
    - 会扎人吗
    - 亲肤吗
  - 透肤度
    - 会透肉吗
    - 厚度够吗
    - 冬天穿会冷吗
  - 搭配性
    - 可以搭配马丁靴吗
    - 可以搭配短裙吗
    - 日常好穿吗
  - 耐用性
    - 会褪色吗
    - 会掉毛吗
    - 会起球吗
- 输出
  - 用户痛点矩阵
  - 购买疑虑清单
  - 竞品表达总结
  - 设计机会点
  - 优先表达建议
- 质量检查
  - 是否能解释用户为什么买
  - 是否能解释用户为什么犹豫
  - 是否把疑虑转成了设计信息
  - 是否避免只做“好看”而不解决问题

## A4 卖点 / 文案策略 Agent

- 定位
  - 把产品事实和用户洞察转成清晰卖点与可上图文案
  - 不负责排版，只负责信息策略
- 输入
  - A1设计Brief
  - A2产品理解卡
  - A3用户痛点矩阵
  - 品牌语气
  - 平台限制
- 核心流程
  - 1. 汇总产品事实
    - 哪些卖点有事实支持
    - 哪些卖点只有推测
    - 哪些卖点不能写得太绝对
  - 2. 建立卖点层级
    - 核心卖点
    - 辅助卖点
    - 证据点
    - 场景卖点
    - 情绪卖点
  - 3. 匹配用户痛点
    - 一个卖点对应一个用户疑虑
    - 一个视觉证据对应一个卖点
    - 避免堆砌无关卖点
  - 4. 生成文案方向
    - 功能型文案
    - 场景型文案
    - 情绪型文案
    - 对比型文案
    - 品牌型文案
  - 5. 撰写画面文案
    - 主标题
    - 副标题
    - 卖点标签
    - 功能说明
    - 场景说明
    - CTA行动语
  - 6. 进行文案风控
    - 删除绝对化表达
    - 删除无依据承诺
    - 删除平台禁词
    - 降低夸张语气
    - 保留可信表达
  - 7. 生成文案版本
    - 点击率优先版本
    - 品牌感优先版本
    - 转化解释优先版本
    - 极简高级版本
- 输出
  - 卖点结构
  - 文案矩阵
  - 主标题方案
  - 副标题方案
  - 标签文案
  - 风险词清单
- 质量检查
  - 主卖点是否足够明确
  - 文案是否能解决用户疑虑
  - 文案是否有事实依据
  - 文案是否适合放进画面
  - 文案是否过长

## A5 参考 / 视觉方向 Agent

- 定位
  - 找设计灵感，但核心不是堆参考图
  - 负责把参考拆解成可执行的视觉语言
- 输入
  - A1设计Brief
  - A4卖点文案
  - 品牌风格
  - 目标平台
  - 设计趋势或参考库
- 核心流程
  - 1. 确定参考关键词
    - 产品品类关键词
    - 场景关键词
    - 风格关键词
    - 人群关键词
    - 平台关键词
  - 2. 收集参考
    - 同品类优秀案例
    - 跨品类优秀案例
    - 平台高转化案例
    - 品牌视觉案例
    - 字体与版式案例
  - 3. 拆解参考图
    - 构图方式
    - 信息层级
    - 色彩关系
    - 字体气质
    - 产品展示方式
    - 光影氛围
    - 图文比例
    - 视觉焦点
  - 4. 筛选可用元素
    - 可以借鉴的版式
    - 可以借鉴的色彩
    - 可以借鉴的材质表现
    - 可以借鉴的标题形式
    - 不适合本项目的元素
  - 5. 形成视觉方向
    - 方向一：强转化直接表达
    - 方向二：品牌高级感表达
    - 方向三：场景种草表达
  - 6. 生成Moodboard说明
    - 情绪关键词
    - 色彩关键词
    - 字体关键词
    - 构图关键词
    - 素材表现关键词
- 输出
  - 参考拆解报告
  - 视觉方向建议
  - Moodboard结构
  - 可借鉴元素清单
  - 避免照抄清单
- 质量检查
  - 是否只是找图，还是完成了拆解
  - 是否能转成实际版式
  - 是否符合品牌与产品
  - 是否避免直接照抄

## A6 设计规划 Agent

- 定位
  - 在执行前把策略转成画面方案
  - 解决“怎么排、先看什么、哪里放什么”的问题
- 输入
  - A1设计Brief
  - A2素材诊断
  - A4卖点文案
  - A5视觉方向
  - 平台尺寸要求
- 核心流程
  - 1. 确认画布参数
    - 尺寸
    - 比例
    - 分辨率
    - 安全区
    - 输出格式
  - 2. 规划信息层级
    - 第一眼：产品或主标题
    - 第二眼：核心卖点
    - 第三眼：辅助信息
    - 最后：品牌或CTA
  - 3. 规划构图方式
    - 左图右文
    - 上图下文
    - 中心构图
    - 对角线构图
    - 模块化构图
    - 对比构图
    - 场景沉浸式构图
  - 4. 规划素材使用
    - 主图放哪里
    - 细节图放哪里
    - 背景怎么处理
    - 是否需要放大框
    - 是否需要对比图
    - 是否需要图标辅助
  - 5. 规划文字区域
    - 主标题区域
    - 副标题区域
    - 卖点标签区域
    - 说明文字区域
    - 品牌区域
  - 6. 规划视觉风格
    - 色彩方案
    - 字体方案
    - 光影方案
    - 背景方案
    - 装饰元素方案
  - 7. 生成执行任务清单
    - 新建画布
    - 处理主体素材
    - 处理背景
    - 排主标题
    - 排副标题
    - 加卖点标签
    - 做细节展示
    - 做视觉统一
    - 输出多版本
  - 8. 生成版本策略
    - V1：稳妥转化版
    - V2：高级品牌版
    - V3：场景种草版
- 输出
  - 版式规划
  - 信息层级表
  - 素材摆放方案
  - 执行任务清单
  - 多版本设计策略
- 质量检查
  - 是否能直接交给执行Agent制作
  - 是否明确每个元素的位置和作用
  - 是否符合用户第一眼阅读路径
  - 是否避免信息堆砌

## A7 执行生产 Agent

- 定位
  - 根据设计规划生成设计稿
  - 可对接Photoshop、Figma、UXP、图片生成工具或自动化脚本
- 输入
  - A6设计规划
  - 素材文件
  - 文案文件
  - 品牌资产
  - 输出规格
- 核心流程
  - 1. 建立项目文件结构
    - 创建画布
    - 设置尺寸
    - 建立图层组
    - 导入素材
    - 命名图层
  - 2. 处理产品素材
    - 抠图
    - 修瑕疵
    - 调色
    - 统一光影
    - 提升清晰度
    - 保持产品真实感
  - 3. 处理背景
    - 纯色背景
    - 渐变背景
    - 场景背景
    - 氛围光背景
    - 材质背景
  - 4. 执行排版
    - 放置主视觉
    - 放置主标题
    - 放置副标题
    - 放置卖点标签
    - 放置细节图
    - 放置Logo和CTA
  - 5. 做视觉统一
    - 字体统一
    - 色彩统一
    - 间距统一
    - 圆角统一
    - 阴影统一
    - 图标风格统一
  - 6. 生成多版本
    - 按构图生成版本
    - 按色彩生成版本
    - 按文案强度生成版本
    - 按场景氛围生成版本
  - 7. 输出初稿
    - 预览图
    - 源文件
    - 可编辑文件
    - 版本说明
- 输出
  - 初稿设计
  - 多版本方案
  - 可编辑源文件
  - 预览文件
  - 图层结构说明
- 质量检查
  - 是否严格执行A6规划
  - 是否保持产品真实
  - 是否图文清晰
  - 是否文件结构干净
  - 是否方便后续修改

## A8 审核优化 Agent

- 定位
  - 负责判断设计稿是否合格
  - 不是只看好不好看，而是按商业设计标准审核
- 输入
  - A7初稿
  - A1设计Brief
  - A4卖点文案
  - A6设计规划
  - 平台要求
- 核心流程
  - 1. 检查需求匹配
    - 是否符合任务类型
    - 是否符合平台尺寸
    - 是否符合品牌方向
    - 是否包含必须元素
  - 2. 检查卖点表达
    - 第一眼是否能看懂核心卖点
    - 卖点是否和产品事实一致
    - 卖点是否解决用户疑虑
    - 证据是否足够
  - 3. 检查视觉层级
    - 主视觉是否突出
    - 主标题是否突出
    - 辅助信息是否不抢主次
    - 阅读路径是否顺畅
  - 4. 检查排版质量
    - 对齐
    - 留白
    - 间距
    - 字号
    - 行距
    - 字重
    - 图文比例
  - 5. 检查素材质量
    - 是否模糊
    - 是否变形
    - 抠图是否干净
    - 光影是否统一
    - 产品颜色是否失真
  - 6. 检查文案风险
    - 是否使用绝对化用词
    - 是否有无依据承诺
    - 是否有平台敏感词
    - 是否夸大功效
    - 是否语义不清
  - 7. 检查品牌一致性
    - 色彩是否一致
    - 字体是否一致
    - 语气是否一致
    - 视觉气质是否一致
  - 8. 检查商业转化
    - 是否有点击理由
    - 是否有信任理由
    - 是否有场景代入
    - 是否减少购买疑虑
  - 9. 给出修改意见
    - 按严重程度分级
    - 标记必须改
    - 标记建议改
    - 标记可不改
  - 10. 决定流转
    - 通过：进入A9交付
    - 文案问题：退回A4
    - 版式问题：退回A6
    - 执行问题：退回A7
    - 素材问题：退回A2
- 输出
  - 审核报告
  - 评分表
  - 修改建议
  - 退回原因
  - 是否通过
- 质量检查
  - 审核是否具体
  - 修改建议是否可执行
  - 是否指出问题位置
  - 是否说明为什么要改

## A9 交付 / 复盘 Agent

- 定位
  - 负责最终输出、文件管理、版本归档、经验沉淀
  - 让设计结果形成可复用资产
- 输入
  - A8通过的最终稿
  - 源文件
  - 项目状态文件
  - 导出要求
- 核心流程
  - 1. 检查交付清单
    - 是否有最终图
    - 是否有源文件
    - 是否有预览图
    - 是否有文案记录
    - 是否有设计说明
  - 2. 导出文件
    - JPG
    - PNG
    - PSD
    - 按项目需要选择
  - 3. 文件命名
    - 品牌产品平台用途尺寸版本日期
    - 示例：品牌过膝袜淘宝主图1080x1080V03_20260610.jpg
  - 4. 整理文件夹
    - 01_Brief
    - 02_Assets
    - 03_References
    - 04_Drafts
    - 05_Final
    - 06_Source
    - 07_Review
    - 08_Learnings
  - 5. 生成交付说明
    - 本次设计目标
    - 最终采用卖点
    - 设计方向说明
    - 文件列表
    - 使用注意事项
  - 6. 复盘沉淀
    - 哪些卖点有效
    - 哪些版式有效
    - 哪些问题被反复修改
    - 哪些素材质量影响效率
    - 哪些规则可以变成模板
  - 7. 更新知识库
    - 保存成功案例
    - 保存失败原因
    - 保存可复用版式
    - 保存可复用文案
    - 保存审核规则
- 输出
  - 最终交付包
  - 文件命名清单
  - 交付说明
  - 复盘报告
  - 可复用模板
  - 知识库更新记录
- 质量检查
  - 文件是否齐全
  - 命名是否规范
  - 源文件是否可编辑
  - 是否有交付说明
  - 是否完成复盘沉淀

## 2. Agent协作退回规则

- 信息不完整
  - 退回A1需求采集 Agent
- 产品或素材判断不清
  - 退回A2商品 / 素材理解 Agent
- 用户痛点不明确
  - 退回A3用户 / 市场洞察 Agent
- 卖点不清或文案有风险
  - 退回A4卖点 / 文案策略 Agent
- 视觉方向不匹配
  - 退回A5参考 / 视觉方向 Agent
- 版式规划不清
  - 退回A6设计规划 Agent
- 执行质量不达标
  - 退回A7执行生产 Agent
- 审核不通过
  - A8根据问题类型选择退回节点
- 交付文件不完整
  - 退回A9交付 / 复盘 Agent

## 3. 第一版开发合并方案

- 模块1：总控 / 需求模块
  - 合并A0总控编排 Agent
  - 合并A1需求采集 Agent
  - 目标：把用户需求转成设计Brief和任务流程
- 模块2：商品 / 市场分析模块
  - 合并A2商品 / 素材理解 Agent
  - 合并A3用户 / 市场洞察 Agent
  - 目标：理解产品、素材、用户疑虑和市场表达
- 模块3：卖点 / 文案模块
  - 对应A4卖点 / 文案策略 Agent
  - 目标：输出可上图的卖点和文案
- 模块4：参考 / 规划模块
  - 合并A5参考 / 视觉方向 Agent
  - 合并A6设计规划 Agent
  - 目标：确定视觉方向并形成可执行版式
- 模块5：执行生产模块
  - 对应A7执行生产 Agent
  - 目标：生成设计稿和多版本方案
- 模块6：审核 / 交付模块
  - 合并A8审核优化 Agent
  - 合并A9交付 / 复盘 Agent
  - 目标：检查质量、导出文件、复盘沉淀

## 4. 最终推荐架构

- 长期架构
  - 1个总控Agent
  - 9个专业Agent
  - 合计10个逻辑Agent
- 第一阶段落地
  - 合并成6个执行模块
  - 先保证流程闭环
  - 再逐步拆细能力
- 核心判断
  - 不建议只做6个原始Agent
  - 原始信息收集Agent过大，必须拆分
  - 原始执行器Agent过大，必须拆成规划和执行
  - 必须增加复盘沉淀，否则无法形成长期设计能力

## 5. 每次项目的标准运行顺序

- 1. 用户输入需求与素材
- 2. A0判断任务类型和缺失信息
- 3. A1生成设计Brief
- 4. A2分析产品和素材
- 5. A3分析用户痛点和市场表达
- 6. A4提炼卖点和文案
- 7. A5确定视觉参考和风格方向
- 8. A6生成版式规划和执行清单
- 9. A7制作初稿和多版本
- 10. A8审核并退回修改或通过
- 11. A9导出交付并复盘沉淀
