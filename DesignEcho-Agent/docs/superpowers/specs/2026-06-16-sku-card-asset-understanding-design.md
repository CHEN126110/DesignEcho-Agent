# SKU 卡片色卡与项目素材理解设计

## 目标

把 `E:\DesignEchoDemo\C-1194` 作为第一场真实考试，让 Agent 完成卡片式 SKU 色卡生产的前置理解、模板准备、批量执行和结果复核。

本阶段不追求“万能 SKU 设计”，而是先让 Agent 稳定做一件事：理解项目素材，选出适合 SKU 卡片的图片，生成 `2双装`、`3双装`、`4双装` 以及对应自选备注，并把结果保存回当前项目目录。

## 背景

用户希望 Agent 像设计师一样工作：边做、边看、边判断，而不是直接套模板脚本。

当前系统已有 SKU 执行器、项目素材索引、视觉抽样计划、配置化执行计划、导出读回和部分视觉复核入口。但这些能力还没有组成一个稳定的 SKU 卡片工作流：

1. Agent 还不能稳定判断哪些项目图适合 SKU。
2. SKU 执行器偏脚本生产，模板或配置不符时容易直接失败。
3. 智能对象、剪切蒙版、图片置入、缩放和审美复核没有成为 SKU 前置流程的一部分。
4. 用户可见回复不能暴露内部工具细节，应从真实使用角度说明“看图、选图、做卡片、复核效果”。

## 范围

### 做

1. 项目素材理解。
2. 项目内 SKU 候选图检索。
3. 卡片式 SKU 色卡选图。
4. SKU 模板和配置准备检查。
5. 必要时参考 `D:\DesignEchoDemo\C-1137` 的完成态项目复刻卡片结构。
6. 使用 Photoshop 能力进行置入、智能对象、剪切蒙版、缩放和导出。
7. 输出 `2双装`、`3双装`、`4双装` 和对应自选备注。
8. 对导出结果做尺寸、数量、位置和视觉复核。
9. 以真实效果作为最终验收。

### 不做

1. 不做纯色背景 SKU 色卡精修。
2. 不做复杂抠图、边缘修复、阴影重绘、布料质感修补。
3. 不把主图、详情页和 SKU 合并成一个硬编码 executor。
4. 不把项目 `模板文件` 和 `配置文件` 泛化成主图、详情页的通用前置条件。
5. 不因为脚本执行完成就声称设计质量合格。

纯色背景色卡需要更强的精修能力，后续作为独立能力处理。

## 方案选择

### 方案 A：继续让 SKU 脚本直接跑

优点：改动少。

缺点：模板、配置、图片位置不合格时只能失败；Agent 仍然像脚本，不像设计师。

结论：不采用。

### 方案 B：全量视觉理解项目图片

优点：理论上理解充分。

缺点：慢、贵、不可扩展；每个项目几十张甚至上百张图片，不能全量看大图。

结论：不采用。

### 方案 C：元数据索引 + 有界视觉候选 + SKU 卡片前置检查

优点：速度快，能复用缓存；只让视觉模型看少量候选图；模板和配置先检查再执行；适合逐步扩展到主图和详情页。

缺点：需要补齐候选分类、SKU 卡片评价标准和执行前门禁。

结论：采用。

## 工作流

### 1. 建立项目素材索引

Agent 先读取项目目录，不调用视觉模型。

索引使用以下证据：

1. 文件路径。
2. 文件夹名。
3. 文件扩展名。
4. 图片尺寸。
5. 文件大小。
6. 修改时间。

初筛分类：

| 分类 | 说明 |
| --- | --- |
| `sku-card-candidate` | 可能适合做 SKU 卡片色卡 |
| `model-wearing` | 模特上脚图，适合主图或详情页 |
| `detail-closeup` | 袜口、面料、圆点、弹力等细节图 |
| `group-display` | 多色组合展示图 |
| `scene-lifestyle` | 场景氛围图 |
| `not-suitable` | 主体不完整、遮挡严重、重复或用途不明 |

`平铺` 目录中的图片优先进入 SKU 候选，`模特` 目录中的图片默认不进入 SKU 首选候选，但可以作为视觉参考或详情页素材。

### 2. 有界视觉理解

Agent 不全量看图。

默认策略：

1. 从项目索引中选出最多 8 张 SKU 候选。
2. 优先覆盖不同颜色、不同拍摄角度、单品和组合图。
3. 使用缩略图或低成本视觉理解判断是否适合 SKU 卡片。
4. 写入视觉缓存。

缓存 key 至少包含：

```text
path
sizeBytes
mtime
width
height
```

图片变化才重新理解。

### 3. SKU 卡片选图标准

每张候选图输出结构化判断：

```text
path
assetRole
skuCardScore
visibleColors
subjectCompleteness
cropRisk
backgroundInterference
angleConsistency
recommendedUse
needsHumanReview
```

评分重点：

1. 袜子主体是否完整。
2. 颜色是否容易区分。
3. 是否适合裁进卡片。
4. 画面是否干净。
5. 是否有明显手部、道具或背景干扰。
6. 同一组卡片的角度和大小是否统一。

### 4. 模板和配置准备

SKU 卡片执行前必须确认：

1. 当前项目是否已有 `模板文件`。
2. 当前项目是否已有 `配置文件`。
3. 模板是否覆盖 `2双装`、`3双装`、`4双装` 和对应自选备注。
4. 配置是否能被正确解码，优先兼容 UTF-8、GB18030、GBK。
5. 配置中的模板名是否能匹配项目模板。
6. 配置中的颜色槽数量是否不超过可用 SKU 候选或颜色组数量。

如果模板或配置缺失，Agent 不应直接跑脚本，而应进入模板准备：

1. 参考 `D:\DesignEchoDemo\C-1137` 的 SKU 成品结构。
2. 生成或调整当前项目的 SKU 卡片模板。
3. 生成对应配置。
4. 再进入脚本执行。

### 5. Photoshop 执行方式

Agent 应理解以下 Photoshop 操作语义：

| 操作 | 使用场景 |
| --- | --- |
| 置入图片 | 把项目素材放入卡片容器 |
| 智能对象 | 需要可替换、可缩放、可保持质量的图片槽 |
| 剪切蒙版 | 限制图片只显示在卡片区域内 |
| 缩放和移动 | 让主体大小、重心和留白统一 |
| 导出 | 输出 SKU 卡片图和自选备注图 |
| 读回 | 检查导出文件、尺寸和关键视觉风险 |

执行必须是批量计划式，而不是一张图一轮对话。

推荐顺序：

```text
打开或生成模板
确认卡片槽位
批量置入图片
建立智能对象或复用智能对象
建立或检查剪切蒙版
统一缩放和位置
批量导出
读回导出图
抽样视觉复核
失败项返工
```

### 6. 视觉复核标准

导出后不能只看脚本是否成功。

必须检查：

1. 文件是否存在。
2. 图片尺寸是否符合 SKU 输出标准。
3. 每个规格数量是否符合计划。
4. 卡片内主体是否完整。
5. 同组袜子大小是否接近。
6. 颜色是否能看清。
7. 标签是否遮挡商品。
8. 卡片间距是否稳定。
9. 是否像真实淘宝 SKU 图，而不是测试拼图。

如果复核失败，Agent 应给出面向用户的描述：

```text
这组 4 双装里右下卡片主体偏小，我会调整缩放后重新导出这一组。
```

不要输出：

```text
replaceSmartObjectContents failed
skuLayout execute returned mismatch
placementAudit status warning
```

内部诊断可以保留在结构化结果里，但不直接暴露给普通用户。

## 效率原则

极致效率不是跳过观察，而是按成本分层。

执行顺序：

```text
元数据扫描
缩略图候选
有界视觉理解
模板/配置门禁
批量 Photoshop 写入
导出读回
抽样视觉复核
失败项返工
```

硬原则：

1. 便宜证据先行。
2. 贵的视觉模型限量使用。
3. Photoshop 写入集中执行。
4. 结果复核只看关键风险点。
5. 看过的素材要缓存，避免重复理解。
6. 失败只返工失败项，不整批重做。

## Skill 边界

### `project-image-analysis`

负责项目素材理解和候选分类。

不直接生成 SKU。

### `sku-batch`

负责 SKU 卡片生产、配置化执行、导出和读回。

进入执行前必须具备项目素材证据、模板证据、配置证据或明确的模板准备计划。

### `main-image-design`

不使用 SKU 模板配置作为前置条件。

可以复用项目素材理解结果选主图素材。

### `detail-page-design`

不使用 SKU 模板配置作为前置条件。

可以复用项目素材理解结果选详情页素材。

## 用户可见状态

Agent 对用户说人话：

```text
我先看这批素材里哪些适合做 SKU 卡片。
这批图里平铺图更适合做色卡，模特图先留给主图和详情页。
我会先确认 2、3、4 双装和自选备注的卡片结构，再统一导出。
这张图主体完整，但背景干扰稍多，不作为第一候选。
```

避免：

```text
执行 skuLayout。
读取 ProjectAssetIndex。
调用 VisualSamplingPlan。
解析 configured execution plan。
```

## 验收

第一场考试通过标准：

1. Agent 能说明 `E:\DesignEchoDemo\C-1194` 中哪些素材适合 SKU 卡片。
2. Agent 不把模特图误当成主要 SKU 卡片素材。
3. Agent 能准备或检查 `2双装`、`3双装`、`4双装` 和对应自选备注条件。
4. Agent 能把模板和配置保存到当前项目目录。
5. Agent 能批量输出 SKU 卡片图。
6. Agent 能读回导出文件并检查数量、尺寸和关键视觉问题。
7. Agent 能以用户可理解语言反馈结果。
8. 如果模板、配置或素材不合格，Agent 会先说明并修正条件，不会盲跑脚本。

## 风险

1. Photoshop 智能对象和剪切蒙版工具虽然已有接口线索，但真实稳定性还需验证。
2. 当前视觉复核可能只能做到结构和抽样审美检查，不能替代人工最终审美判断。
3. 如果 UXP runtime 版本过旧，SKU 递归颜色组或无占位符自动排版能力可能不可用。
4. CSV 可能是 GBK/GB18030 编码，不能默认 UTF-8。
5. 淘宝参考页因浏览器安全策略无法直接访问，第一场考试以本地成品项目为参考。
