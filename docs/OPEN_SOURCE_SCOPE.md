# 开源边界

公开仓库提供 DesignEcho 的运行时代码、Photoshop UXP 工具、浏览器桥、通用测试、公开架构文档和社区维护配置。

以下内容明确不属于公开仓库：

- 客户、品牌或店铺的真实素材与项目文件
- PSD、PSB、TIF、原始摄影文件和商业模板
- Eagle 个人库、标签、文件夹和检索结果导出
- API 密钥、Provider 配置、账号信息和本机运行状态
- ONNX 模型、模型缓存、依赖缓存和构建产物
- 内部任务日志、长期运行记忆、调试截图和验收导出
- 未确认再分发权的图片、字体、模型和第三方文档

## 贡献者检查清单

1. `git status` 中没有 `.env`、模型、素材或构建目录。
2. 示例路径使用通用 fixture，不含用户名、店铺名或真实项目根目录。
3. 测试令牌是明确构造的 synthetic fixture，不是可用凭据。
4. 新增二进制资产具有明确来源和再分发权。
5. 真实 Photoshop 证据只保留脱敏摘要，不提交项目源文件。

公开仓库不是私有工作区的完整镜像。内部运行记忆和真实项目证据应继续保存在受控环境中。
